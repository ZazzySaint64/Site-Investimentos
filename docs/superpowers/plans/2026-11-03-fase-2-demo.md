# Fase 2: painel do demo e publicação. Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Um visitante abre o site pela URL pública e, em um clique e sem criar conta, vê uma carteira fictícia com valor, resultado, alocação e posições, calculados com preços reais.

**Architecture:** Duas tabelas públicas guardam personas e transações fictícias. Um comando Python grava esses dados uma vez, a partir de CSVs versionados. O Next.js lê do banco e calcula as posições em TypeScript, em uma função pura. Nada é salvo como posição.

**Tech Stack:** Next.js, TypeScript, Tailwind, `node --test`, Playwright, Python 3.12, Supabase, Vercel.

**Spec:** `docs/superpowers/specs/2026-11-03-site-investimentos-design.md`

**Escopo:** só o que a fase 2 entrega. A nota de saúde fica para a fase 4. `demo_recommendations`, `demo_answers` e o motor de regras ficam para a fase 6. Ações EUA e cripto ficam para as fases 7 e 8, então as carteiras de exemplo têm só ativos do Brasil.

### Task 3: Cálculo da carteira

- Produces:

```ts
export type DemoTransaction = {
  id: number;
  type: "buy" | "sell";
  quantity: number;
  price: number;
  date: string;
  asset: {
    ticker: string;
    name: string;
    class: string;
    sector: string | null;
    active: boolean;
    prices: { close: number; date: string }[]; // no máximo 1: o mais recente
    splits: { date: string; ratio: number }[];
  };
};

export type Position = {
  ticker: string;
  name: string;
  assetClass: string;
  sector: string | null;
  active: boolean;
  quantity: number;
  averageCost: number;
  cost: number;
  price: number | null;
  priceDate: string | null;
  value: number | null;
  result: number | null;
  share: number | null;
};

export type Portfolio = {
  positions: Position[]; // maior valor primeiro; sem preço por último
  invested: number; // custo do que continua na carteira
  value: number; // só posições com preço
  result: number; // aberto das posições com preço + realizado nas vendas
  resultShare: number; // result / total comprado; 0 se nada foi comprado
  realized: number;
  allocation: { assetClass: string; value: number; share: number }[]; // maior primeiro
  missingPrices: string[];
};

export function computePortfolio(transactions: DemoTransaction[]): Portfolio;
```

Algoritmo: por ativo, em ordem de data e, no mesmo dia, compras antes de vendas. Quantidade e preço corrigidos por `ratio` de datas estritamente posteriores: quantidade × produto, preço ÷ produto. Compra soma ao custo. Venda reduz o custo pelo preço médio e soma (preço − médio) × quantidade ao realizado.
